教研阅记桌面版 0.1.2 · 安装须知

此安装包由项目源码构建，提供 Windows x64 桌面程序及 Electron 运行环境。

使用前需部署完整教研阅记项目，准备 Docker Desktop 和自己的 PostgreSQL。AI 功能按需接入自己的模型服务。首次打开请选择包含 docker-compose.yml、scripts 和 app 的完整项目文件夹。

安装包不携带其他用户的论文、笔记、数据库、模型令牌或私有配置。数据库与模型配置在自己的完整项目 private 目录中保管。

可选择安装位置。桌面连接设置、草稿、缓存和日志保存在安装目录旁的 JiaoyanDesktopData，升级和卸载时保留。业务资料由完整项目与 PostgreSQL 保存。

关闭窗口时先确认未保存内容，然后自动停止本项目 Web 与 PaperFlow 容器；请等待退出窗口消失。系统安装的 PostgreSQL 服务继续运行，完整便携部署会停止自带数据库。Docker Desktop 和其他项目保持运行。

桌面接入代码按 MIT 许可证提供。Electron 与 Chromium 的第三方许可证随安装目录提供。业务项目及字体、画作来源见完整项目 UPSTREAM.md 和 THIRD_PARTY_NOTICES.md。

本地构建未配置代码签名证书。请从可信来源获取安装程序。
