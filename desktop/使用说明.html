教研阅记 · 桌面版

首次配置

先下载完整项目，按PostgreSQL 本机部署说明配置自己的数据库，启动 PostgreSQL 服务与 Docker Desktop。在本文件夹双击 setup.cmd，脚本会联网下载桌面运行依赖。

AI 为可选配置。使用者在父项目的 private/model.env 填写自己的接口、模型 ID 与令牌；数据库连接填写在 private/postgres.env。这些私有文件只在本机保管。

打开

双击父项目的 打开教研阅记.cmd，或本文件夹的 启动桌面版.cmd、launch.cmd。程序自动准备本项目后台并进入工作区，重复打开会回到已有窗口。文献库、批注、回收站、笔记公式、复习、研究记忆、多文献知识图谱与教育研究速递沿用网页版功能。

保存与导出

已保存的资料由桌面版与浏览器共用，未提交草稿分别保存，切换前请先保存。上传使用系统文件选择窗口；导出时可选择保存位置，默认放在 .local/downloads。论文与期刊外部链接在系统浏览器打开。

关闭

直接关闭窗口，或选择“工作区 → 退出桌面版”。未保存的编辑会先提示确认。确认关闭后，程序自动停止本项目的 Web 与 PaperFlow 容器；已保存的论文、笔记和批注会保留。启动中关闭会等启动操作完成后再停止。

等待“正在退出教研阅记”窗口自动消失。系统安装的 PostgreSQL 服务、Docker Desktop 和其他项目保持运行；自行配置完整便携部署时，项目自带数据库也会停止。同一工作区的浏览器页面在后台停止后暂时离线，重新打开桌面版即可恢复。

意外退出后可运行父项目的 停止Demo.cmd。使用外置盘时，退出完成后通过 Windows“安全删除硬件”弹出磁盘。

文件与空间

桌面依赖和运行资料集中在本文件夹。.cache 保存下载缓存；.local/profile 与 .local/session 可能包含未提交草稿，请保留。PDF、数据库和私有配置沿用完整项目的位置。

自行生成安装包

本仓库不含已构建的安装包。完成依赖安装后可运行 build-installer.cmd，结果生成在 dist；安装包仍需完整后台、Docker Desktop 与已配置的 PostgreSQL。详细步骤见 安装与分发.md。

连接问题

使用“工作区 → 重新连接”，或运行父项目的 检查Demo.cmd。“帮助 → 打开桌面日志”可查看本机日志。更多目录与开发说明见 README.md。
