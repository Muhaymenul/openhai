# 教研阅记 Windows 桌面端：构建、安装与分发

本仓库提供 Electron 桌面源码与构建脚本，**不包含已构建的安装包**。从源码使用时先运行 `setup.cmd`、再运行 `launch.cmd`；需要安装向导时，可自行按下文构建 Windows x64 安装包。

## 自行构建安装包

在完整项目的 `desktop/` 目录中：

1. 双击 `setup.cmd`，联网下载本目录专用的 Node.js、Electron 与桌面依赖。
2. 双击 `build-installer.cmd`，或运行：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-installer.ps1
   ```

3. 在生成的 `dist/` 中取得 `Jiaoyan-Desktop-<版本号>-Setup-x64.exe` 及同名 `.exe.sha256` 校验文件。版本号来自 `package.json`。

构建脚本运行桌面检查，校验下载的打包工具，并复用已安装的 Electron。打包白名单只包含桌面源码、元数据、图标、说明和许可，不包括论文、笔记、数据库、令牌及本机运行记录。构建工具与缓存集中在本目录，构建不会自动上传安装包。

## 安装与首次打开

1. 先在接收者电脑下载完整项目，按 [PostgreSQL 本机部署](../docs/PostgreSQL部署.md) 配置自己的数据库，并启动 PostgreSQL 服务和 Docker Desktop。
2. 填写完整项目中的 `private/postgres.env`。AI 按需配置：将自己的接口、模型 ID 与令牌填在 `private/model.env`；私有文件留在本机。
3. 双击自行构建的安装文件，按向导选择独立安装目录，不要覆盖完整项目的源码目录。
4. 通过桌面或开始菜单中的“教研阅记”打开，首次选择包含 `docker-compose.yml`、`scripts` 与 `app` 的完整项目文件夹。
5. 程序准备本项目后台并进入工作区，以后会记住所选项目。

安装版包含 Electron，使用时无需另装 Node.js、Electron 或运行 npm。完整后台、Docker Desktop 和 PostgreSQL 仍需单独部署；只发送安装 `.exe` 不能完成全部部署。源码版的 `launch.cmd` 继续可用，两种入口共用已保存的业务资料，未提交草稿分别保存。

## 日常退出与资料位置

关闭桌面窗口或选择“工作区 → 退出桌面版”，未保存的编辑会先提示确认。确认后自动停止所选项目的 Web 和 PaperFlow 容器；启动中关闭会等启动操作结束后再停止。等待“正在退出教研阅记”窗口消失即可。系统安装的 PostgreSQL 服务和 Docker Desktop 继续运行；自行配备完整便携环境的项目会同时停止自带数据库。其他项目的容器保持运行。

| 位置 | 内容 |
| --- | --- |
| 安装目录 | 桌面程序及 Electron 运行组件 |
| 安装目录旁 `JiaoyanDesktopData/` | 安装版连接设置、草稿、浏览器存储、日志和默认导出文件 |
| 完整项目 `data/` 与 PostgreSQL | PDF、批注和已保存的研究业务资料 |
| 完整项目 `runtime/`、`private/` | 后台会话、日志及私有配置 |

程序意外退出后可使用完整项目的 `停止Demo.cmd`。切换到另一份占用相同本机端口的项目前，先保存并关闭当前桌面端。外置盘请在退出完成后通过 Windows 安全弹出。

通过 Windows 应用列表或安装目录中的卸载程序卸载桌面版。卸载保留独立桌面资料及原业务数据；清理前请自行备份。

## 分享给其他人

分享自己生成的 `.exe`、同名校验文件、本说明和完整源码仓库链接。接收者按上述步骤部署自己的后台与数据库，填写自己的模型配置。不要发送 `private/`、个人数据库、论文库、草稿、运行日志或备份。

当前构建配置未启用代码签名，正式公开分发可进一步配置签名与版本发布流程。仓库本身不承诺现成 `.exe` 下载；实际可下载的安装包应以单独发布的 Release 资产为准。
