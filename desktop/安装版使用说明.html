教研阅记 · 安装版说明

本说明供从源码自行构建的安装版使用。仓库提供桌面源码与打包脚本，不附带已构建安装包。在 desktop 完成 setup.cmd 后，可用 build-installer.cmd 生成自己的 Windows x64 安装包。

安装前准备

先下载完整项目，部署自己的 PostgreSQL 和 Docker Desktop。数据库步骤见PostgreSQL 本机部署。在完整项目的 private/postgres.env 填写自己的数据库连接；AI 接口、模型 ID 和令牌按需填写在 private/model.env，私有文件留在本机。

自行构建的安装包包含 Electron，安装后无需再安装 Electron、Node.js 或运行 npm。它继续依赖完整项目和本机后台，不附带开发者的数据库或资料。

首次打开与日常使用

通过桌面或开始菜单中的“教研阅记”打开。首次请选择已经配置好的完整项目文件夹，其中应包含 docker-compose.yml、scripts 和 app。程序会记住所选目录，准备本项目后台后进入工作区。重复打开会回到已有窗口。

文献库、阅读批注、回收站、笔记公式、学习复习、研究记忆、多文献知识图谱和教育研究速递与网页版共用。上传通过文件选择窗口完成，导出可自行选择位置，外部链接在系统浏览器打开。

关闭

关闭窗口或选择“工作区 → 退出桌面版”。未保存的编辑会提示确认。确认后自动停止所选项目的 Web 与 PaperFlow 容器；启动中关闭会先等待启动操作结束。等待“正在退出教研阅记”窗口自动消失，已保存资料会保留。

系统安装的 PostgreSQL 服务、Docker Desktop 和其他项目保持运行。自行配备专用便携数据库的项目会同时停止自带 PostgreSQL。意外退出时，可运行完整项目的 停止Demo.cmd 补充停止后台。

资料与卸载

业务资料保存在所选项目与 PostgreSQL。安装版的连接设置、未提交草稿、浏览器缓存、日志和默认导出文件保存在安装文件夹旁的 JiaoyanDesktopData。源码版与安装版的草稿分别保存，切换前请先保存内容。

卸载桌面程序会保留独立桌面资料、论文和数据库。需要迁移或清理时，请先备份自己需要的文件。

遇到问题

运行完整项目的 检查Demo.cmd，或通过“帮助 → 打开桌面日志”查看连接状态。后台恢复后选择“工作区 → 重新连接”。
