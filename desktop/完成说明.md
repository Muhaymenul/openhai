# 桌面入口接入说明

桌面源码版本为 0.1.2，与完整父项目的 Web、PaperFlow 和 PostgreSQL 共用已保存资料。仓库提供源码、固定依赖锁文件和打包脚本，运行依赖通过 `setup.cmd` 下载，安装包由使用者按需生成。

## 使用

1. 按根目录 README 配置自己的 PostgreSQL 和可选模型接口，启动 Docker Desktop。
2. 首次在 `desktop` 运行 `setup.cmd`，随后双击根目录的 `打开教研阅记.cmd` 或本目录 `launch.cmd`。
3. 关闭窗口时先处理未保存内容，随后自动停止本项目后台；等待退出窗口消失。系统安装的 PostgreSQL 服务保持运行，完整便携部署会同时停止自带数据库。

安装与分发见 [安装与分发](安装与分发.md)，当前架构和验证结果见 [软件架构](../docs/software/architecture.md) 与 [发布验收](../docs/software/validation.md)。本机生成的浏览器资料、日志和验收截图留在忽略版本控制的 `.local/` 内。
