# 功能规格

基线日期：2026-11-01。下表描述现有 Demo 的功能及发布时需要复核的行为；优先级用于后续维护排序。

## 1. 功能清单

| 编号 | 功能与优先级 | 用户操作与结果 | 验收重点 |
| --- | --- | --- | --- |
| F01 | 文献库，P0 | 导入文字 PDF，修改题名、作者、年份、主题和标签，记录阅读状态与位置。 | 刷新和重启后能找到原文件、元数据和阅读位置；失败的导入显示可处理的错误。 |
| F02 | 阅读批注，P0 | 选择原文高亮、写评论；使用原生高亮、文本框、手写及页面便签。 | 高亮和评论保存进实际 PDF；摘录保留来源页；重复提交不产生重复条目。 |
| F03 | 批注整理，P0 | 从批注列表选择条目，整理成草稿，在统一编辑器预览并保存。 | 原文摘录和个人想法保持可区分；整理过程无需调用模型。 |
| F04 | 阅读助手，P0 | 提问、生成论文卡、分析方法与证据、解释概念；查看任务进度、取消或恢复历史。 | 显示真实任务状态；断线或取消保留已产生内容；写入建议需由用户确认。 |
| F05 | 解释选文，P0 | 对选中文段解释、举例或继续深入；提交自己的复述并获取反馈。 | 保留选文页码和正文版本；补充解释与论文主张可区分，支持回看原文。 |
| F06 | 学习笔记，P0 | 明确选择整篇、选文、批注或已保存笔记作为材料，生成后编辑保存。 | 展示所选材料范围；用户核对后入库；生成结果不覆盖已编辑笔记。 |
| F07 | 逐题复习，P1 | 生成 3、5 或 8 题，点击开始后逐题作答、查看答案、自评；继续或只练未掌握题。 | 保存题组和已提交进度；支持编辑、暂停题目；未提交输入暂存在当前浏览器。 |
| F08 | 研究笔记，P0 | 创建 Markdown 笔记、预览、修改、查看历史版本，人工确认并回跳来源。 | 版本冲突时要求刷新核对；个人检索只纳入已确认笔记。 |
| F09 | 教育概念库，P1 | 阅读四个预置入门条目，新增或编辑概念、别名及出处。 | 保留来源字段；概念条目作为可编辑的阅读提示使用。 |
| F10 | 个人检索，P0 | 查询论文、页面、批注和已确认笔记，可选择个人材料或教育概念范围。 | 中文查询可返回对应页面；被移入回收站的资料不进入可见检索结果。 |
| F11 | 证据图谱，P1 | 本地匹配或显式发起 AI 提取，筛选论文、节点和关系；确认或拒绝候选，回看证据。 | 摘录入库前核对原文；重复提取不重复加边、不重置拒绝；正文变化后标记旧证据。 |
| F12 | 研究待办，P1 | 建立、编辑、完成或归档任务，关联论文；解析日期建议并导出 ICS。 | 日期按北京时间处理，保存前可修改；ICS 含提前 15 分钟提醒，交由个人日历执行。 |
| F13 | 导出与备份，P0 | 导出 Markdown、带批注 PDF、图谱 JSON/图片或研究成果 ZIP；通过完整备份入口保存服务数据。 | 导出内容可打开，来源保留；完整备份包含 data 与 runtime，模型凭据单独保管。 |
| F14 | 设置与服务状态，P0 | 配置自己的 OpenAI 兼容 API，查看模型及服务状态。 | 未配置或额度不足时说明原因；模型凭据不进入公开仓库和成果导出。 |

P0 为阅读闭环和数据保存的基础能力，P1 为学习和研究整理能力；两类均已有对应实现。

## 2. 主要流程

1. 启动本机服务，打开 `/workspace`，导入示例或自己的 PDF。
2. 阅读并选择原文，写入批注，按需要发起解释或提问。
3. 选定材料生成或人工整理笔记，编辑、核对来源并保存；确认后进入个人研究检索。
4. 生成自测题，主动开始复习，作答后查看答案并自评。
5. 查看关系候选及双方证据，确认或拒绝，导出本次成果。

## 3. 资料范围与状态规则

- 阅读助手默认以当前论文为来源；用户可明确勾选其他论文，合计最多 4 篇。选择变化时相应隔离任务与会话范围。
- 学习操作按整篇、选文、批注或笔记的明确选择生成。单次整篇分析正文上限为 10 万字符，截断时显示范围提示；其余页面仍可阅读和检索。
- 图谱本地匹配产生“涉及概念”“共同涉及概念”等候选；AI 提取使用“讨论”“使用方法”“报告观点”等关系。关系状态为候选、已确认、已拒绝，来源变更另标记待重新定位。
- 论文移入回收站后，关联成果按可见性规则隐藏；恢复论文后保留记录。复习关联笔记或正文发生变化时需重新核对题组。
- 自测采用本机简单复习间隔，由用户自评；不自动判分。日期解析为本地规则建议，用户确认后保存。
