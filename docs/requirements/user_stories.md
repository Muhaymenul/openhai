## 验收场景

### AC01：导入并继续阅读

给定一个带文字层的 PDF，当用户导入、修改标签并阅读到某页后关闭页面，再次进入时，应找到该论文、已保存元数据和阅读位置。导入和建索引不调用模型。

### AC02：批注进入 PDF 并保留来源

给定用户选中原文，当其创建高亮并写评论后，侧栏应分别显示摘录与想法，刷新后仍存在；导出 PDF 可查看标记。重复发送同一次保存请求不增加重复记录，旧窗口修改遇到版本冲突时需刷新核对。

### AC03：只使用选定资料解释

给定库中有多篇论文且未选择其他来源，当用户解释当前选文时，应保留选文及页码；工具不能读取未选论文。用户明确选入其他论文后，来源列表与引用应能区分论文及页码。未配置 API 时显示配置入口，不消耗其他服务的额度。

### AC04：草稿、编辑与确认

给定已生成的笔记草稿，当用户预览、修改并保存时，应保存用户修改及来源；再次生成草稿不覆盖已有笔记。未确认笔记不进入个人研究检索，确认后可以被检索，版本历史仍可查看。

### AC05：主动开始逐题复习

给定用户选择材料并生成 3、5 或 8 题，当题组就绪时，应由用户点击开始；作答后可看答案并自评。重新进入可继续已提交的进度，并可只练未掌握题；浏览器尚未提交的回答按本机暂存处理。

### AC06：图谱候选有可核对证据

给定论文中出现概念名称或别名，当用户生成本地关系候选时，应展示原文页码和摘录。AI 提取返回的摘录若不在指定页，不应入库。拒绝一条关系后再次提取，关系不恢复为候选；正文变化后原证据需标记重新定位。

### AC07：日期确认与日历导出

给定输入“明天下午五点整理阅读笔记”，当用户查看日期建议时，应显示北京时间并允许修改；确认保存后可完成、编辑或归档任务。导出的 ICS 提前 15 分钟提醒由个人日历处理。

### AC08：成果导出与完整恢复

给定已保存的批注、笔记、图谱与复习记录，当用户导出成果时，应可打开对应文件并查看来源；当执行完整服务备份并在独立目录恢复时，已保存数据和服务记录应完整。模型凭据由用户单独配置。

## 首轮试用记录计划

计划邀请 3–5 人，依次完成 AC01、AC02、AC03、AC04、AC05 和 AC06，另选一名参与者演练 AC07、AC08。记录每项任务是否独立完成、首次求助位置、来源核对是否成功、发现的问题及改进建议。招募、执行与结果分析列入[项目计划](../mgmt/plan.md)，本文件不填写尚未获得的结果。
