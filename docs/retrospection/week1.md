## 本轮得到的认识

1. 原始 MindBranch 构想覆盖多格式材料、WASM、向量和主动通知；当前 Demo 已形成更具体的 PDF 阅读与学习闭环。课程文档应围绕可运行路径展开，后续方向单独列入计划。
2. “有出处”需要落实到数据和操作：页码、摘录、正文版本、人工确认及过期提示共同支撑回看证据。模型返回结构正确仍需核对关系含义。
3. 检索由 FTS5、中文补充规则和工具逐页检索共同组成。清楚描述各自范围，比把整个流程统称为 BM25 更有助于后续评估。
4. 文件真源和可重建 SQLite 使个人部署较直接；成果导出与完整服务备份用途不同，需要在安装和演示中说明。
