# 教研阅记使用说明

教研阅记把论文原文、批注、研究笔记、复习题和知识图谱放在同一个本机工作区。可以从“读原文 → 划线提问 → 编辑笔记 → 逐题自测 → 继续复习”开始。

## 启动与停止

项目文件夹为你 clone 或解压的 `openhai` 目录。首次部署与模型接入步骤见[仓库首页](../README.md)。

1. 双击 `启动Demo.cmd`，等待浏览器打开 <http://127.0.0.1:3000/workspace>。需要在当前电脑上运行 Docker Desktop；启动脚本会检查本机服务。
2. 使用完毕可关闭网页。需要停止后台服务时，双击 `停止Demo.cmd`，论文、笔记和图谱会保留。
3. 网页打不开时，运行 `检查Demo.cmd`。先确认 Docker Desktop 正常，再重新运行启动脚本。

安装桌面入口后，可双击“打开教研阅记（openhai）”或“关闭教研阅记（openhai）”，无需输入命令。关闭只停止本项目的后台服务，保留论文、笔记和复习记录，也不会关闭 Docker Desktop。关闭网页本身不会停止后台服务。若启动失败，按提示查看 `runtime/launcher` 中的日志。

打开应用先进入封面首页。底部三个入口分别打开文献库、研究笔记与知识图谱；“继续阅读”返回最近阅读的论文与页码。点击工作区左上角“教研阅记”可回到首页。

## 首页导航、搜索与画廊

- 点击“查找论文”或按 Ctrl + K，输入题名、作者或标签。点击结果打开论文，Enter 打开首条结果；Esc 关闭搜索。这里查找本机文献库，不访问外部文献平台。
- 点击底部“文献库”“研究笔记”或“知识图谱”，直接进入对应工作区。
- “继续阅读”保留当前浏览器最近阅读的位置。
- 首页的八幅经典画作自动循环淡变。点击画作暂停，再点击继续播放；使用键盘时，聚焦画作后按空格或 Enter。
- 打开搜索、切换到其他浏览器标签页或画廊移出屏幕时，播放自动暂停。返回后沿用原来的播放进度。系统开启“减少动态效果”时默认静止，也可点击画作主动播放。

封面使用本地画作文件，包括《雅典学院》《圣礼之争》《帕尔纳索斯山》《赫利奥多罗斯被逐出圣殿》《授钥》《利未家的宴会》《圣马可在亚历山大布道》和《最后的晚餐》。首页导航、搜索与画廊播放均在本机完成。

## 在应用内查使用说明

点击左侧导航底部的“使用说明”，或顶部的问号按钮，即可打开应用内帮助。也可直接访问 <http://127.0.0.1:3000/workspace?view=help>。

在“搜索使用说明”中输入“删除评论”“草稿”或“备份”等关键词，可查对应步骤和常见问题。点击功能标题展开详细说明。首次使用时先到文献库导入示例或自己的 PDF。

## 先用示例论文练习一次

新安装的文献库从空白开始。在文献库点击“导入示例论文”，加入形成性评价、自我调节学习和设计型研究三份原创合成测试 PDF；也可以上传自己的论文。示例用于体验操作，不作为真实研究证据。AI 步骤请先按[模型接入说明](../README.md#首次接入自己的-ai)填写自己的接口、模型 ID 和令牌。

1. 点击论文卡片打开原文，拖选一段你想理解的文字。
2. 点击选文下方的“提问”，输入“这段话是什么意思？能举个例子吗？”并发送。也可在“更多选文操作”选择“直接解释选文”；用“检查我的理解”写一句自己的复述，对照原文反馈。
3. 打开右侧“笔记”，点击“整理重点”，将材料范围选为“当前选文”。生成后点“编辑为笔记”，修改、预览、核对来源并保存草稿。
4. 点击“生成自测题”，选择材料和 3、5 或 8 题。就绪后先保存手头的修改，再点“开始逐题复习”；先回答，再看答案，自评“会了”或“还不会”。
5. 在“学习复习”找到题组，继续进度或只练未掌握的题。在“研究笔记”审核草稿并“确认入库”，之后可从个人检索找回。

不使用 AI 时，可以先划线、写评论，从批注整理笔记并保存。符合问答格式的笔记可加入复习；普通笔记不会自动生成复习进度。

| 阅读工作台 | 阅读、高亮、文本框、手写、评论与摘录               | 这些操作不使用模型；解释选文与发送问题会使用 |
| 研究笔记   | 编辑、预览、保存草稿、确认入库、导出笔记           | 否                                           |
| 学习复习   | 逐题作答、自评、继续进度、编辑或暂停题目           | 练习已有题组不使用；生成新题会使用           |
| 教育概念库 | 查看概念和出处，补充自己的参考条目                 | 浏览和编辑不使用模型                         |

| 知识图谱   | 查看关联、核对原文证据、确认或拒绝候选、导出       | 本地“整理关系候选”不使用模型                 |

## 导入与整理文献

在文献库点击“导入论文”，选择或拖入 PDF。可以一次选择多篇，应用会依次处理。当前单份文件上限为 100 MB；重复导入同一份原始 PDF 会复用已有论文记录。

导入后，点击卡片下方“编辑信息”，核对题名、作者、年份、研究主题、标签和阅读状态，再保存。题名会优先使用 PDF 自带信息，自动取得的内容仍需要核对。

文献卡自动显示 PDF 第一页作为封面，不使用模型。封面暂不可用时显示文件图标，仍可正常打开论文阅读。

主题适合区分研究课题，例如“学位论文”“文献计量”或“智能体”；标签适合交叉标记，例如“待读”“研究方法”“可复现”。同一论文可有多个标签。

使用主题下拉框和“未阅读”“阅读中”“已读完”缩小范围。打开“筛选标签”，勾选一个或多个标签；多选表示论文必须**同时具备全部所选标签**。例如同时选择“方法”和“教育”，只显示两个标签都有的论文。

文献库内的搜索框查找题名、作者、年份、主题和标签；这些条件可以与标签、阅读状态同时使用。已选标签显示在结果上方，可逐个移除；“清除筛选”会重置主题、阅读状态、搜索词和标签，保留当前排序与视图。

通过“文献排序”选择“最近导入”“最近更新”或“标题 A–Z”。长标题较多时可切换到列表视图。要搜索论文正文，请使用“个人检索”。

### 删除与恢复文献

1. 点击文献卡下方“删除”，核对题名后选择“移入回收站”。如相关分析还在运行，先到“任务与设置”停止分析。
2. 在文献库右上角打开“回收站”，点击“恢复”，论文会连同笔记、批注、研究关系和复习进度一起恢复。
3. 回收站文献暂不参与检索、图谱、新分析和复习；引用它的笔记或题组也会暂时隐藏。旧来源链接需要先恢复才能访问。重复上传回收站里的同一份 PDF 时，也会提示先恢复。

回收站不自动清空，也不释放文件占用的磁盘空间。PDF 原件与关联记录仍保存在本机，并包含在备份中。其他窗口会同步文献状态；未保存的笔记文字会保留，恢复文献后可继续保存。

## 阅读与批注

点击论文进入阅读工作台。桌面左侧是 PDF，右侧有“阅读助手”“笔记”“批注”三个页签；窄屏时上下排列。使用上一页、下一页、缩放与全屏按钮阅读。普通打开会恢复当前浏览器记住的位置，点击来源页码则跳转到指定页。

点击顶部标题旁的信息图标（“查看论文信息”），可查看完整题名、作者、年份、页数和主题。顶部“PDF”按钮用于打开论文文件，已保存的 PDF 批注会随文件保留。

### 调整阅读区域大小

拖动 PDF 与右侧工作区之间的分隔条，可调整左右宽度；窄屏上下排列时，拖动分隔条调整上方 PDF 的高度。比例会记住在当前本机浏览器中。点击工具栏中的缩放百分比，可以让原文适合当前阅读区域的宽度。

也可以用 Tab 将焦点移到分隔条，再用键盘调整：桌面用左右方向键，窄屏用上下方向键；按住 Shift 可加快调整，Home 和 End 可移到允许的最小或最大范围。双击分隔条，或点击“恢复默认阅读布局”图标按钮，可还原宽度和高度的默认比例。

### 常用工具与选文批注

主工具栏保留“选择”“写评论”和“更多”。使用“选择”拖选原文，选文下方会显示快捷操作：

- **高亮**：一键写入 PDF，保留当前阅读页签，可继续阅读。
- **写想法**：保留选文及来源页，再填写自己的理解或疑问。
- **提问**：把这段原文带到阅读助手，输入自己的问题后发送。
- **更多选文操作 → 高亮颜色**：选择黄色、绿色、蓝色或粉色；当前浏览器会记住颜色。
- **更多选文操作 → 直接解释选文**：无需输入问题，直接获得讲解。
- **更多选文操作 → 保存摘录为笔记**：把选文放入可编辑笔记草稿。

保存新高亮后，提示中可点击“撤销”；在同一处重复高亮会复用已有记录，显示“此处已有高亮”，不会叠加一条重复记录。高亮、写想法和摘录不调用模型；只有发送问题、直接解释等生成操作使用额度。

### 更多原生工具

“更多”中保留原生高亮、文本框、手写和页面便签。修改约在停止操作 **1.8 秒后自动保存**；失败时点击“重试”，确认保存完成再离开。需要导出时，点击顶部“PDF”，已保存的标准批注会随文件保留。

这些工具以 PDF 内标记为主。需要在侧栏查看、添加想法并整理原文摘录时，请使用选文下方的快捷“高亮”。

### 打印阅读记录与论文全文

在阅读工作台按 Ctrl + P，打印的是当前阅读区的文字记录与论文信息。需要打印论文全文时，先保存 PDF 批注，再点击顶部“PDF”，从 PDF 阅读器使用打印功能，并检查打印预览。已保存的批注保留在打开的 PDF 中。

### 写评论

点击工具栏“写评论”或右侧“批注”中的“添加评论”，填写后点击“保存评论”，也可在“写评论”窗口按 **Ctrl / Cmd + Enter** 保存。

普通评论默认关联当前可见页，可展开“更改页码”调整；从选文发起时，原文与来源页固定，避免写到另一页。

### 查看、修改与整理批注

“批注”页签默认显示简洁列表，区分高亮与评论，原文和“我的想法”分开显示。用“搜索原文或想法…”查找内容；点击“当前页”只看当前阅读页，再点击恢复全部。点击页码返回原文，“提问”把该条的原文带到阅读助手。

点击 PDF 中的高亮或评论标记，只打开一张卡片。可“添加想法”“编辑想法”或“提问”；长内容在卡片内滚动，点击空白处或按 Esc 关闭。批注不会因为鼠标经过就弹出黄色浮层。

只有高亮、没有想法的条目也能保留。编辑高亮时可保存空想法，清除个人文字但保留标记；普通独立评论需有正文。删除前会在页面内确认，成功后从 PDF 与列表一起移除。外部阅读器的批注可能只读，不会按显示的作者名字开放编辑。

关闭未保存的想法时，在页面内选择“继续编辑”或“放弃修改”；继续编辑会保留输入。另一个窗口仍显示旧内容时，刷新批注或重新打开论文。

整理笔记的步骤：

1. 点击“整理成笔记”进入选择模式，默认选中当前列表中的批注；搜索与“当前页”筛选会影响列表范围。
2. 取消不需要的条目，或用“全选”切换；不整理时点击“取消”回到普通列表。
3. 点击“生成草稿”，在统一笔记编辑器修改标题和正文，切换“编辑 / 预览”检查内容。
4. 核对来源后“保存草稿”。已成功本机暂存时可直接关闭；需要用于个人检索时，再到“研究笔记”确认入库。

批注整理按页码保留引用与想法，不调用 AI。

出现“记录已被修改”或“PDF 已改变”时，先复制保留当前输入，再刷新并核对最新内容。应用会拒绝旧版本保存，避免覆盖其他窗口中的新批注。

## 阅读助手与解释选文

### 提出一个明确问题

先在 PDF 中选中文字，点选文操作条的“提问”，再输入问题。输入框上方会显示选文和页码；点击叉号可移除选文范围。没有选文时，也可直接围绕当前论文提问。Enter 发送，Shift + Enter 换行，生成时可点击“停止”。

默认是**自由讨论**：模型可以结合自身知识与参考概念，解释、举例、比较或讨论研究想法，不要求固定段数和回答模板。论文具体观点与数据仍需要真实原文依据，模型补充不能当作作者结论。

需要核查论文证据时，开启**“仅依据原文”**，切换为原文核对；关闭后回到自由讨论。论文卡、图谱提取、整理笔记、自测题和理解检查仍以各自选定材料为依据。

可以直接问：

> 这段话想说明什么？换一个生活中的例子。

> 结合自我调节学习，解释这里的监控与反思有什么联系。

> 作者为什么采用这个方法？请区分原文说明和你的推测。

### 参考概念与连续追问

“概念”默认**自动匹配**：参考与问题或选文有关的概念，不会为了引用而强行套用无关理论。展开可手动选择条目，最多 4 个；点击“不参考”关闭概念参考，点击“自动匹配”恢复自动选择。采用的概念显示为标签，可逐个移除。没有匹配条目时仍能正常提问。

同一段选文可连续追问“为什么？”“再举一个例子”或“有什么适用条件？”。回答会联系同一讨论范围；更换选文、回答方式或参考资料时，会分别保留讨论范围，避免混用旧来源。

较长对话会为本次回答保留近期交流与较早讨论的摘录，完整历史记录仍可回看。较早细节可能需要你重新指出，这不代表模型有无限上下文窗口。

### 跨论文来源与历史讨论

展开“提问来源”勾选其他论文。当前论文始终保留，额外最多选 3 篇，合计最多 4 篇；“仅当前论文”可重置。未选择的论文不会自动加入。

自由讨论先载入少量相关段落，必要时继续查阅所选论文；不要把回答视为已完整阅读全文。提问时说明比较目标，查看回答时分别核对每篇论文与页码。论文卡和学习操作以当前论文或各自“材料范围”为准。

每条回答上方的“这次提问”保留当时的方式、概念、选文和来源。展开“来源”或“提交的选文”可核对；在“近期讨论”重看旧回答后，点击“沿用此次来源”再继续提问。之后更换资料不会改写旧记录。旧记录缺少信息时会提示，不会猜测补齐。

未发送的问题会暂存当前浏览器，刷新后可恢复；生成解释不会清空另一条问题草稿。历史状态也可在“任务与设置 → 分析任务”中查看。已完成任务的“分析过程”默认收起，点击可展开。

### 读懂一段原文

1. 在 PDF 中拖选文字，“提问”后自己输入问题；或打开“更多选文操作 → 直接解释选文”。
2. 点击“举个例子”，得到便于理解的例子；点击“深入解释”，继续拆解概念、前提和论证。
3. 点击“检查我的理解”，用自己的话复述。应用根据同一段原文指出准确之处、遗漏和需要修正的内容，不自动给分。
4. 点击来源页码核对原文，修正表达。想解释另一段时，重新选择文字再发起解释。

点击回答的“编辑为笔记”，会带入**原文、问题、回答和“我的思考”**；修改、预览并核对来源后保存，不会自动写入 PDF 或覆盖已有笔记。

类比帮助理解，不能代替论文证据。发送问题、直接解释、举例、深入解释和检查理解使用现有模型额度；查看历史、编辑和保存已有结果不调用模型。

## 整理重点与生成自测题

阅读页右侧“笔记”页签提供两个入口：

| 操作       | 解决的问题                         | 结果                             |
| ---------- | ---------------------------------- | -------------------------------- |
| 整理重点   | 怎样把阅读材料整理成可查阅的笔记？ | 可编辑的标题、线索、要点与总结   |
| 生成自测题 | 我是否能独立回想和解释这些内容？   | 3、5 或 8 道有答案与来源的复习题 |

### 先选材料范围

点击其中一个入口后，先在“材料范围”选择：

| 范围       | 使用的材料                           |
| ---------- | ------------------------------------ |
| 整篇论文   | 当前论文可用正文，仍受长材料范围限制 |
| 当前选文   | 刚刚在 PDF 中选中的那段文字          |
| 已有批注   | 你勾选的批注及相关来源页             |
| 已保存笔记 | 你选定的那一份笔记及其来源           |

缺少选文、批注或笔记时，对应选项不可用。生成前核对题名、范围和所选条目，避免把整篇与局部材料混淆。范围内材料过长时会截断并提示；必要时拆成更小的选文或批注集合。

来源笔记或批注在生成期间被修改、删除时，应用会要求核对当前版本后重新生成。不会把旧材料生成的题目直接挂到新版本上。

### 编辑并保存重点笔记

1. 点击“整理重点”，选择范围后“生成笔记草稿”。
2. 生成完成后，在结果中点击“编辑为笔记”，再修改标题与正文。切换“编辑”“预览”检查排版。
3. 打开来源页，核对并加入自己的理解，点击“保存草稿”。看到“已保存”后再关闭；之后可从阅读页“继续编辑”。
4. 需要用于个人检索时，到“研究笔记”审核并点击“确认入库”。

生成结果需要显式保存到工作区。已本机暂存的内容可直接关闭或刷新，未暂存时才提示；普通笔记编辑不会自动覆盖已有内容。

### 生成题组

1. 点击“生成自测题”，选择范围与 3、5 或 8 题。
2. 点击“生成自测题”。完成后结果提示题目已就绪；先保存正在编辑的 PDF 批注或笔记，再点击“开始逐题复习”，将题目、参考答案和来源保存到本机并进入练习。
3. 已保存笔记可使用“用这份笔记复习”。符合明确问答格式的笔记可直接加入题组；其他笔记需要生成题目。

生成新题使用模型额度；进入已有题组、作答、自评、编辑和继续复习不调用模型。

## 学习复习

### 先作答，再核对与自评

1. 打开左侧“学习复习”，按论文或来源笔记筛选题组，点击“开始复习”或“继续复习”。
2. 每次显示一道题，参考答案默认隐藏。在“我的回答”写下理解，也可以先在心中作答。
3. 点击“查看参考答案”，核对自己的回答与来源页码。
4. 自己选择“会了”或“还不会”，再点击“下一题”；最后点击“完成本轮”。应用记录自评，不使用模型自动判分。
5. 想集中补缺，点击“只练未掌握”，或完成后的“重练未掌握”；也可“全部再练一遍”。

“已掌握”依据你最近一次自评显示，不是模型对理解能力的评分。

### 保存、继续与修正题目

- 输入中的回答先暂存当前浏览器。点击查看答案、自评或跳题后，回答与进度写入本机工作区；看到“回答已保存”或自评记录后再离开。刷新后可继续原题。
- 浏览器禁止本地暂存时，页面会提示。此时先点击“查看参考答案”保存回答，再离开页面。
- “编辑题目”可修正题干、答案；修改后重新自评。暂时不适合的题目可“暂停此题”，在“已暂停”中恢复。
- 来源显示“已更新”时，旧题目和进度仍保留，请回看原文后修正或重新出题。发生版本冲突时，先保留当前回答，再“重新载入”，避免覆盖另一窗口的新记录。
- 论文或题组引用的资料进入回收站后，关联题组暂时隐藏；恢复资料后保留原进度。

### 下次复习时间

当前采用简单本机间隔：“还不会”约 10 分钟后，“会了”约次日。这个时间用于安排再次回顾，**不采用 FSRS，也不会自动推送通知**；请自行打开应用继续复习。

## 显示设置与长论文

### 调整助手字号

点击右侧页签末尾的“Aa”，选择“小 13px”“中 14px”或“大 16px”。默认使用“中”，当前浏览器会记住选择。这只调整右侧文字；PDF 原文大小仍用阅读器的缩放工具调整。

界面、笔记和图谱的英文优先使用本机 Michelangelus，中文优先使用华文宋体（STSong）；PDF 原文字体由文件本身决定。换到其他电脑时，需在那台电脑安装相应字体，未安装时会使用可用的回退字体。

### 长论文的范围

论文卡和整篇精读分析最多载入前 **10 万字符**；较长论文的后部内容可能不在本次分析中。自由讨论采用选文、相关概念和少量相关段落，必要时按问题查阅所选论文，而非每次把全文加入对话。

全部页面仍可阅读和本地检索。研究后部章节时，可在 PDF 中选中相关原文再提问；长对话用近期交流和较早摘录缓解上下文占用，仍受模型窗口上限影响。没有文字层的扫描件仍能阅读和批注，本版不会自动 OCR。

## 笔记草稿与确认入库

“草稿”表示内容还在整理，“已确认”表示你已审核，并允许它进入个人研究检索。保存草稿与确认入库是两个步骤。

1. 在“研究笔记”打开一条笔记，或点击“新建笔记”。填写标题、正文，并选择关联论文。
2. 正文可以直接输入普通文字；点击“预览”检查显示效果。
3. 点击“原文依据”的页码核对来源，加入自己的理解并修正模型表达。
4. 点击“保存”或按 **Ctrl / Cmd + S** 写入工作区；审核完成后点击“确认入库”。保存后继续修改同一条笔记。

### 本机草稿与恢复

- **本机草稿**：内容暂存于当前浏览器，尚未写入项目。可直接关闭、切笔记、查看原文或刷新，再打开原笔记恢复；未保存的生成稿也可在“研究笔记 → 本机草稿”中恢复，无需重新生成。
- **已保存**：内容已写入本机工作区。后台不会因为你输入文字就自动新建笔记或调用模型。
- **未保存**：尚未写入工作区；浏览器无法暂存时会明确提示，请在刷新或关闭前手动保存。

本机草稿不进入工作区备份，清除浏览器数据会删除它。需要长期保留的内容请点击保存。已保存笔记的关联论文固定。

### 遇到新版本时

另一个窗口修改了笔记后，编辑器会保留当前文字并阻止旧版覆盖。点击“查看当前版本”比较，再选择“保留草稿并打开新版本”或“将草稿另存为新笔记”。

如果提示本机草稿已在另一窗口改变，先“另存本机草稿”，再继续处理。仅未成功暂存或存在暂存冲突时，离开操作才显示“继续编辑 / 继续离开”；保存提交期间仍会阻止意外刷新。

需要简单排版时，可使用以下 Markdown 写法：

```text
# 我的阅读笔记

## 主要发现
- 第一条要点
- 第二条要点

> 一段原文摘录
```

自测问答在预览中会折叠答案。需要把已有问答笔记直接加入复习时，使用下列明确格式；普通说明文字不会被自动猜成题目：

```text
### 问题1：这里填写问题
答案：这里填写参考答案与来源页码。
```

修改已经确认的笔记时，“保存”会更新其已确认版本，请先核对内容。

## 个人检索与概念库

“个人检索”可查论文信息、全文片段、阅读批注及已经确认的笔记。输入关键词后，可切换“个人研究知识库”“教育概念库”或“所有资料”。点击结果标题、页码或来源打开相应内容。

在工作区按 Ctrl + K 可聚焦顶部搜索框，输入后按 Enter 进入检索页；在封面首页，它打开本机论文快速搜索。关键词过长或过于笼统时，换用一个有区分度的概念、方法名或原文短语。

新保存的草稿不会进入个人研究检索。若笔记找不到，先检查是否已“确认入库”。

教育概念库目前是可编辑的参考条目集合。查看条目时核对出处；添加条目时填写名称、解释和资料来源。它不是完整百科，论文分析中的具体结论仍应回到原文。

## 知识图谱

“研究网络”展示论文、概念和笔记；“论文关系”只展示论文之间的连接。可按论文筛选，或搜索节点名称、解释；搜索保留命中节点及一阶相邻节点，筛选时保留节点位置。

缩小或窄屏时保留论文名；点选、悬停或放大可查看概念与笔记名称，右侧列表保留完整名称。

- 点击画布节点、连线或右侧“节点”“待核对”列表，同步选中并查看详情。节点详情中的“只看相邻”可聚焦局部，点击画布上方“返回全图”退出。
- 点击“整理关系”更新本地候选；候选用虚线显示，可用“候选关系”开关隐藏。点击关系查看两端节点、原文摘录和来源页码，核对后“确认关系”或“拒绝”；点击两端节点可继续浏览。
- 拖动节点调整位置，滚轮或＋/－按钮缩放。聚焦画布后也可按＋/－缩放、0 适应画布。“适应画布”调整显示范围，“重新布局”重新排列节点。
- 打开“导出”，选择“当前图谱 PNG”保存当前筛选范围的图谱，或“完整数据 JSON”保存完整图谱数据。

## 研究待办与日历

在“任务与设置”中切换到“研究待办”。可以点击“新建”，也可以输入“明天下午五点三十分完成精读”并点击“填写待办”。

应用会先填入表单，尚未建立待办。核对标题、**北京时间**、优先级和关联论文后，再点击“保存待办”。不支持或不明确的日期请手动填写。

完成事项可点击圆形完成按钮；需要暂时收起时归档，在“已归档”中可恢复。点击关联论文可回到阅读工作台。

“导出日历”下载 ICS 文件，需手动导入自己的日历软件。文件为待完成事项附带提前 15 分钟的提醒。应用没有在网页关闭后自行发送系统推送的功能，日历通知由你使用的日历软件负责。

## 导出 备份与恢复

| 需要保留什么           | 操作入口                             |
| ---------------------- | ------------------------------------ |
| 研究笔记               | 研究笔记 → 导出笔记，下载 Markdown   |
| 当前带批注 PDF         | 阅读页顶部 → PDF                     |
| 图谱图片或结构         | 知识图谱 → 图片导出按钮或导出 JSON   |
| 可见研究成果           | 任务与设置 → 工作区设置中的 ZIP 下载 |
| 整个应用数据与模型历史 | 项目文件夹中的 `备份Demo.cmd`        |

完整备份时，脚本会暂时停止服务，将文献数据、已保存的复习记录与模型服务历史统一备份到 `backups` 文件夹，再重新启动。尽量先结束正在运行的分析，保存自己的笔记和 PDF 修改；作答时先点击“查看参考答案”或完成自评，把浏览器暂存的回答写入工作区。

需要恢复时：

1. 先再运行一次 `备份Demo.cmd`，保留当前状态。
2. 双击 `恢复备份.cmd`。
3. 把完整备份 ZIP 的路径粘贴到弹出的窗口并按 Enter，文件位于你自己的 `openhai/backups/` 目录；请复制实际 ZIP 文件的完整路径。
4. 等待脚本检查并恢复。原有数据会另存到 `backups/before-restore-*`，不会直接删除。

网页下载的成果 ZIP 不包含模型服务内部会话，不能代替完整服务备份。私有模型配置 `private/model.env` 不进入备份，应另行妥善保管，不要把它当作普通成果分享。

## 额度与本机数据

论文文件、笔记、图谱、复习记录和待办保存在本机项目的 `data` 文件夹，分析历史另保存在 `runtime`。不需要另外配置数据库服务器。尚未提交的作答草稿只保留在当前浏览器，不包含在工作区备份中。

阅读、上传、首页观画与搜索、全文索引、检索、编辑批注、保存笔记、从批注生成笔记、练习已有题组、自评、图谱本地整理和研究待办都不调用模型。发送问题、解释选文、举例、深入解释、检查理解、生成笔记或自测题会使用你配置的模型服务及额度，选定范围的材料会发送至所配置的模型服务。

额度或服务报错时，先到“任务与设置”点击“检查分析服务”，再查看失败任务。应用不会自动充值或切换到另一家收费模型。

## 常见问题

**提问、解释、整理重点、自测该先用哪个？** 围绕某段有具体问题时先选文并点“提问”；只想快速读懂时用“更多选文操作 → 直接解释选文”；需要留存要点用“整理重点”；主动回想用“生成自测题”。

**为什么换了一段文字后不继续上一段讨论？** 不同选文分别保留来源范围。想接着旧讨论时，先在“近期讨论”打开旧回答，点击“沿用此次来源”；也可把需要衔接的内容写进新问题。

**自由讨论能无限记住历史吗？** 不能。当前回答保留近期交流与较早讨论摘录，早先细节可在历史中回看并重新指出；模型仍有上下文窗口上限。

**自评后为什么还要点下一题？** 自评先记录掌握程度和下次时间，保留当前答案方便核对；点击“下一题”再继续。

**为什么生成题目时提示来源已改变？** 来源笔记或批注在生成后发生了修改。先保存并核对当前内容，再重新生成，避免把旧题目当成新版本资料的复习题。

**下滑后又出现 Timeline 或闪记的空白。** 刷新工作区加载新版。应用会在本工作区收起这些已识别的浏览器附加面板，避免产生额外空白，不需要更改论文或笔记数据。

**分屏大小不合适。** 拖动两区之间的分隔条，或用 Tab 聚焦后按方向键调整。双击分隔条或点击“恢复默认阅读布局”，可恢复默认比例。

**Ctrl + P 没有打印论文全文。** 工作区打印的是当前阅读文字记录与论文信息；全文请通过顶部“PDF”进入 PDF 阅读器后打印。

**评论保存后没有在另一个窗口更新。** 刷新批注列表或重新打开论文。若版本冲突，不要覆盖保存，先保留输入并核对新内容。

**原生高亮没有显示在右侧列表。** 如需在侧栏继续添加想法或整理摘录，请用选文下方的快捷“高亮”；“更多”中的原生工具主要操作 PDF 内标记。

**笔记已经保存，但个人检索没有找到。** 检查状态是否为草稿；审核后点击“确认入库”，再使用笔记正文中的具体关键词检索。

**PDF 无法选字。** 它可能是扫描图片。换用有文字层的 PDF，或在问题中提供需要解释的文字；原文件仍可阅读与批注。

**图谱显示很多小节点。** 先按论文筛选，再使用缩放或适应画布，点击右侧关系列表查看证据。

**模型答案中的页码打开了其他论文。** 跨论文来源会打开对应资料，请同时核对论文标题与页码，不能只凭页码数字判断来源。

**关闭浏览器后是否丢失资料。** 已保存的内容保存在本机，关闭网页不删除资料；离开前仍需保存正在编辑的笔记与 PDF 标记。
